# paperless_mobile_document_scanner

A document scanner optimized for paperless mobile built on top of opencv_dart based on the canny edge detection algorithm.

## Getting Started

Run the example app to check out the functions of the scanner.

## Credits

This scanner implementation is inspired by [OSS-DocumentScanner](https://github.com/Akylas/OSS-DocumentScanner), an open-source document scanner also built on top of OpenCV.

This package makes use of the incredible dart package opencv_dart which provides native bindings for a large amount of opencv functions.
